How it is built

A launcher that opens things, and nothing else.

Just Zen used to be a browser with your apps inside it. It is not any more, and that removes most of what a page like this used to have to explain. What is left is small enough to describe in one screen.

What it touches

No web engine of its own

Web apps open in Safari or Chrome. Just Zen renders no pages, stores no cookies, and holds no logins for the sites you use. Your browser's profiles, extensions and passwords stay where they are.

Spotlight, not an index

Documents come from macOS Spotlight as you type. Nothing is copied, catalogued or kept. On Windows it looks in your usual folders instead.

One permission, asked late

Reading which tabs are open needs macOS Automation, asked the first time you use it. Say no and Just Zen simply opens a new tab instead, and stops asking.

Opens, never reads

Applications are launched with open, files with their own app, web apps with a URL. Just Zen has no access to the contents of any of them.

Everything stays here

No account, no sync, no telemetry, no crash reporting. Your panel, your groups and your settings live in your user folder, encrypted with the Keychain where macOS allows it.

Three small pages

The panel and the finder are the only HTML in the app. Each runs sandboxed, with no Node access, and is fenced to its own files by a content security policy and a request filter.

Signing and updates

Signed and notarised

The Mac build is signed with a Developer ID, hardened-runtime enabled, and notarised by Apple before release. Updates are downloaded over HTTPS and their signature is checked before anything is swapped.

Windows is not signed yet

The Windows installer carries no certificate, so SmartScreen will warn the first time you run it. Until that changes, treat the Windows build as the lesser of the two.

Dependencies are few

Dropping the browser dropped nearly all of them: the app ships Electron, the updater, and its own code. Every release runs an audit that fails the build on any advisory with a fix.

Open source

All of it is on GitHub, including the tests that run on every release: the finder, the panel, its order, and a check that a foreign page cannot reach the app's own channels.

Nothing to configure.

Install it, pin a few things, and it stays out of the way.
